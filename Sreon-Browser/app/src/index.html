How Sreon protects your data — full details

Saved passwords, bookmarks & history

Encrypted with AES-256-GCM before they ever touch disk. The encryption key is derived from your workspace password using PBKDF2 (210,000 rounds of SHA-256) — the same approach dedicated password managers use. The password itself is never stored anywhere, in any form; only a salted hash is kept, just to check a later attempt against. If a workspace has no password, its data is still encrypted (never plain text), using a random key generated once on this device — set a workspace password if you want that data to require something only you know.

Per-workspace isolation

Personal and Work each get their own password and their own encryption key. Unlocking one workspace does not decrypt the other's data.

IP address & location

Privacy Mode blocks the WebRTC APIs pages use to leak your real IP address behind a VPN/proxy, and refuses page requests for your geolocation outright. A proxy/Tor address in the field above is the only thing that changes what IP a site actually sees at the network level — no in-page toggle can do that on its own.

What never leaves this device

Nothing. Sreon has no account, no sync server, and sends no analytics or telemetry anywhere. Everything described here lives only in this app's local data folder on this computer.
